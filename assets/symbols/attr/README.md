# 속성 아이콘 (도구 설정이 보이는 아이콘)

아이콘 하나를 **레이어 여러 장**으로 나눴습니다. 앱이 지금 설정에 맞는 레이어만 골라 겹쳐 그립니다.
조합 규칙은 `manifest.json` 에 있습니다.

## 레이어 색
- `ui` : 앱 UI 색(평상·선택·비활성). 기존 아이콘과 같은 방식으로 칠합니다.
- `attr` : 도구에 지정된 실제 색(펜 색 등). 레이어 안의 투명도(형광펜 띠 50%, 채우기 30%)는 그대로 둡니다.

## 파일 이름
`<도구>.<부분>[.<옵션>][.w<단계>].svg`
- 예: `tool.pen.stroke.w3.svg`, `tool.arrow.double.w2.svg`
- manifest 의 `{width}` 는 두께 단계(1~4), `{heads}` 는 single/double 로 바꿔 끼웁니다.
- 세 번째 칸(조건)이 있는 레이어는 그 조건일 때만 그립니다(`fill`, `trail`, `!trail`, `mode=brush`, `mode!=brush`).

## 두께 단계
앱의 실제 두께 값을 4단계로 묶어 씁니다(1 가늘게 · 2 보통 · 3 굵게 · 4 아주 굵게).
두께 프리셋 수가 4개가 아니면 범위를 고르게 4등분해 가장 가까운 단계로 보냅니다.

## 명암 보정 (중요)
흰 펜을 밝은 팔레트에, 검정 펜을 어두운 팔레트에 그리면 안 보입니다.
`attr` 색과 바로 뒤 배경의 명암비(WCAG)가 1.8 미만이면 `attr` 레이어 둘레에 1pt 테두리를 붙입니다.
- 배경이 밝으면 rgba(0,0,0,0.55), 어두우면 rgba(255,255,255,0.7)
- 채우기(`.fill`) 레이어에는 붙이지 않습니다.
- 선택 상태(파란 배경)도 배경으로 보고 같은 규칙을 적용합니다.

## 쓰는 곳 (제안)
- 원형 팔레트 중심(18pt): 지금 도구를 속성 아이콘으로
- 2링 도구 칸(14pt): 각 도구가 마지막으로 쓴 설정으로
- 가로 팔레트 도구 버튼
- 설정을 바꾸는 즉시 다시 그립니다.

## 구현 메모
- Mac: 레이어마다 템플릿 이미지로 불러 색을 입히고 `NSImage(size:flipped:drawingHandler:)` 안에서 차례로 그립니다. 테두리는 같은 레이어를 테두리 색으로 칠해 사방 0.5pt씩 어긋나게 먼저 그리면 됩니다.
- Windows: WinUI 3 는 SvgImageSource 를 그대로 쓸 수 있습니다. WPF 는 SVG 를 직접 못 읽으니, 각 SVG 의 `d` 값을 `Geometry.Parse` 로 읽어 Path 로 그리고 Brush 로 색을 입히세요. 테두리는 같은 Path 를 굵은 Stroke 로 한 번 더 아래에 깝니다.
- 모양이 단순해서, 원하면 SVG 대신 코드로 직접 그려도 됩니다(manifest 가 기준).
