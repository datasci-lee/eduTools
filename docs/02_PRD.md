## 1. 개요
### 1.1 제품 비전
수업 중 **어떤 앱 위에서든** 판서·확대·타이머를 한 앱으로 처리하고, macOS와 Windows에서 같은 방식으로 쓰는 메뉴바·트레이 상주 도구.

### 1.2 문제 정의
01_BRD 2.1의 다섯 문제(앱 위 판서, 확대, 타이머·음악, 멀티 모니터 보존, OS 간 일관성)를 해결한다.

### 1.3 목표 사용자
주 사용자는 강의·수업을 진행하는 강사(마우스·트랙패드·펜 태블릿). 부 사용자는 설정을 배포하는 기관 담당자 [확인 필요].

## 2. 목표 및 지표
### 2.1 제품 목표
1. 판서 모드 진입부터 첫 획까지 키 한 번(`⌃⌥P`/`Ctrl+Alt+P`)
2. 판서·줌·타이머가 서로 방해하지 않고 한 상태 관리자 아래에서 동작
3. 두 OS의 기본 단축키·설정 형식 동일(`AppMod+P` 형식 저장)

### 2.2 핵심 지표 (KPI / North Star)
- North Star: **수업 시간 중 앱 전환 없이 처리한 판서·확대·타이머 조작 수** [가정: 사용 기록은 수집하지 않으므로 파일럿 설문으로 측정, 확인 필요].
- 품질 KPI는 01_BRD 2.3의 성공 지표 표를 따른다.

### 2.3 비목표 (Non-Goals)
App Store 배포, 서버·계정·동기화, 모바일 앱, 콘텐츠·음원 제공, 학습 관리, 사용자 행동 수집.

## 3. 사용자
### 3.1 페르소나
| 페르소나 | 설명 | 핵심 필요 |
|---|---|---|
| P1 대면 강사 | 노트북+프로젝터로 슬라이드·코드를 설명 | 빠른 판서·확대, 쉬는 시간 관리 |
| P2 펜 입력 강사 | 펜 태블릿·iPad(Sidecar)로 판서 | 필압, 임시 지우개, 입력 유실 없음 |
| P3 온라인 강사 | 화면 공유·녹화로 강의 | 판서는 공유에 보이고 강사 전용 UI는 숨김 |
| P4 기관 담당자 | 표준 설정을 배포 | `.pansetting`, 설치 파일, 서명 |

### 3.2 사용자 여정 (User Journey)
`수업 시작(수업 타이머)` → `판서 모드 켬` → `설명하며 판서·도형·텍스트` → `작은 글자는 줌 → 정지 줌에서 판서` → `보드에서 정리` → `판서 저장·내보내기` → `쉬는 시간 타이머(음악)` → `수업 재개`.
