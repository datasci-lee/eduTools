## 1. 개요
### 1.1 문서 목적
PRD의 기능 요구사항(PR-xx)을 구현·시험 가능한 기능 ID(FR-xx)로 분해한다. 세부 동작·수치의 정본은 [`design.md`](design.md)이며 이 문서는 목록·규칙 요약·추적을 맡는다(중복 기술 금지).

### 1.2 작성 기준 및 ID 체계
- 기능 ID: `FR-<영역 2자>-<일련번호 2자리>` (이 제품은 화면 번호 대신 영역을 쓴다. 화면 ID는 04의 `SCR-xx`).
- 영역: TL 도구·팔레트 · IK 판서 · ER 지우개 · BD 보드 · ZM 줌 · PR 발표 보조 · TM 타이머 · MU 음악 · DS 화면·장치 · SV 저장 · ST 설정 · HL 도움말 · SY 시스템.
- OS 열: M = macOS, W = Windows. 현재 모든 기능은 두 OS에 구현됐다(예외는 비고).

### 3.5 처리 규칙 (비즈니스 룰)
| 규칙 | 내용 |
|---|---|
| 모든 도구는 판서 모드에서만 입력 | 모드를 끄면 클릭 통과. 예외: 전역 키 8개 |
| 좌표 | 획·타이머 배지·팔레트 위치는 모니터 UUID + 0~1 비율 좌표 |
| 범위 | 줌 1.25~8, 지우개 8~200, 굵기 1~30, 형광펜 기본 40%, 레이저 0.1~10초, Undo ≥ 100, 프리셋 ≤ 8, 재생목록 ≤ 5, 로컬 곡 ≤ 500 |
| 타이머 | 남은 시간 = 종료 시각 − 시스템 시각(잠자기 복귀 후 재계산). 종료 시각이 과거면 경고 |
| 단축키 | 전역은 앱 수정키(`⌃⌥`/`Ctrl+Alt`)+영문 1글자, 판서는 한 글자 키. 물리 키 위치로 인식(한글 입력 상태에서도 동작) |
| 음악 | 소스는 유튜브/폴더 중 하나, URL은 `https://music.youtube.com/`만, 로컬 경로의 `\\…`·`\??\…` 거부, 재생 실패 곡은 건너뛰고 한 바퀴 전부 실패하면 중단 |
| 설정 호환 | 새 키는 추가 필드(없으면 기본값), 모르는 키 무시, `formatVersion` 불변 |
| 판서 보존 | 모니터 해제·프리셋 전환으로 사라지는 화면의 판서는 정책과 무관하게 보관 |
| 내보내기 | 인코딩·쓰기는 작업 스레드, 진행 중 재요청은 거부 |

| 크롬 없음 | 기본 브라우저로 열기 |
| 음악 폴더 비었음·없음 | 재생하지 않고 "재생할 음악 파일이 없습니다" 표시 |
| 전역 키 등록 실패 | 메뉴에 ⚠ 표시, 설정에서 키 변경 |
| 화면 구성 적용 실패·시간 초과 | 스냅샷으로 복구 |
| 설정 파일 검증 실패 | 가져오기 거부(값 범위·경로 규칙), 현재 설정 유지 |

### 3.7 권한
이 앱에는 계정·역할 권한이 없다. OS 권한만 해당한다.

| OS 권한 | 기능 | 없을 때 |
|---|---|---|
| macOS 화면 및 시스템 오디오 녹음 | 줌, PNG 배경 | 안내 후 제한 |
| macOS 손쉬운 사용 | 키 입력 표시, 클릭 강조, 통과 모드 보조 | 해당 기능만 꺼짐 |
| macOS 자동화(Chrome) | 쉬는 시간 종료 시 탭 닫기 | 미디어 키로 대체 |
| Windows | 별도 권한 없음 (UAC 승격 불필요, `asInvoker`) | - |

## 4. 공통 기능
### 4.1 인증 / 인가
해당 없음(로컬 앱, 계정 없음). 인가는 위 OS 권한으로 대체한다.

### 4.2 로깅 / 감사
Windows: `%LOCALAPPDATA%\EduTools\edutools.log`(이벤트·오류, 값 비밀 없음). macOS: 시스템 로그(NSLog) [확인 필요: 파일 로그 여부]. 감사 목적의 사용자 행동 수집은 하지 않는다.

### 4.3 알림
타이머 사운드·깜빡임, 화면 안내 토스트(전역 키 실패, 연결 해제, 내보내기 폴백), 트레이 알림. 모두 로컬 UI이며 외부 전송 없음.
