## 1. 개요
### 1.1 문서 목적
화면 목록·흐름·사용자 스토리·핵심 화면 구성을 정의한다. 시각 규격(원형 팔레트 기하·아이콘·색)의 정본은 [`design.md`](design.md)(원형 도구 팔레트 절)와 [`icons.md`](icons.md)이며 이 문서는 요약·연결을 맡는다.

### 1.2 디자인 원칙
1. **입력은 판서 모드에서만**, 끄면 투명(클릭 통과).
2. **강사 전용 UI는 작고 끌 수 있게**: 팔레트·배지는 접거나 숨기고(`Tab`) 공유·녹화에서 제외한다.
3. **키보드 우선**: 전역 키 8개 + 판서 모드 한 글자 키, 팔레트도 ↑↓←→로 이동.
4. **한국어 UI**, 한글 입력 상태에서도 단축키 동작(물리 키 위치).
5. **항상 같은 의미**: macOS·Windows가 같은 아이콘 세트·용어·단축키 의미를 쓴다.

### 1.3 공통 UI 가이드 (레이아웃, 컴포넌트, 용어)
| 항목 | 규칙 |
|---|---|
| 창 계층 | 오버레이 < 효과(줌·스포트라이트) < 도구(팔레트·배지) < 안내(도움말·쉬는 시간) < 대화(설정·경고) 5단 |
| 팔레트 면 | 고정 어두운 단색 반투명(불투명도 0.75~0.90), 흰 아이콘 |
| 위치 저장 | 모니터 UUID + 0~1 비율 좌표, 모니터가 없으면 주 모니터 같은 비율 위치 |
| DPI | 모니터별 DPI(Windows Per-Monitor v2), 물리 픽셀 렌더 |
| 용어 | 판서 모드·팔레트·보드·줌·통과 모드·쉬는 시간·화면 구성 (01 용어 정의) |

├─ 판서 모드 (켜기/끄기)
├─ 도구: <현재 도구>            ← macOS
├─ 화면 줌 · 스포트라이트 · 커서 강조 · 키 입력 표시 · 화면 가리개 도구

### 4.6 유효성 검사 규칙
`SettingsRanges`(한 곳)가 값 범위의 정본이다: 줌 1.25~8, 지우개 8~200, 굵기 1~30, 레이저 0.1~10초, 필압 최소 0.05~1, 팔레트 불투명도 저장 0.55~0.90(UI 0.75~0.90), 프리셋 이름 1~40자·최대 8개, 재생목록 ≤ 5(`https://music.youtube.com/`), 음악 폴더 제어문자 불가·`\\`/`\??\` 시작 거부, 쉬는 시간 종료 시각은 현재보다 이후.

## 5. 반응형 / 디바이스 대응
- 모니터 수·해상도·DPI가 달라도 획·배지·팔레트는 비율 좌표로 저장해 같은 상대 위치에 그린다.
- 프로젝터(미러링/확장), iPad Sidecar(macOS), 펜 태블릿·터치 입력을 같은 포인터 경로로 받는다. 손가락 터치는 Sidecar에서 판서로 쓰지 않는다.
- 화면 변경(연결·해제·해상도)은 0.3초 모아 한 번에 처리하고 오버레이를 다시 만든다.

## 6. 접근성 체크리스트
- [ ] 모든 도구·창 이동을 키보드로 할 수 있다(팔레트 ↑↓←→, `Tab` 숨김, `Esc` 단계 해제)
- [ ] 한글 IME에서 텍스트 입력·단축키가 모두 동작한다
- [ ] 색만으로 상태를 구분하지 않는다(현재 도구 강조 + 아이콘·툴팁)
