## 1. 개요
### 1.1 문서 목적
EduTools(수업용 판서·확대·타이머 앱)의 사업 관점 요구사항을 정리해 PRD의 근거로 삼는다. 제품은 2026-10-28부터 개발해 `v0.1.0`·`v0.1.1`을 프리릴리스했으므로, 이 문서는 **기존 제품을 문서 체계(03.02)에 맞춰 역정리**한 유형 B(기존 시스템) 문서다. 기능 규격의 정본은 [`design.md`](design.md)이고 이 문서는 중복하지 않는다.

### 1.2 프로젝트 배경
- 강사는 수업 중 슬라이드·코드·영상 등 **어떤 앱 위에서든** 바로 판서하고, 화면을 확대하고, 수업·쉬는 시간을 관리해야 한다.
- 교실 환경은 노트북+프로젝터, 펜 태블릿·iPad(Sidecar), 화면 공유·녹화가 섞여 있고 PC는 macOS와 Windows가 함께 쓰인다 [가정: 대상 기관의 PC 구성은 확인 필요].
- 판서·줌·타이머를 각각 다른 도구로 쓰면 앱 전환과 설정 이중화가 생긴다 [가정].

### 1.3 용어 정의
| 용어 | 뜻 |
|---|---|
| 판서 모드 | 화면 위 투명 오버레이가 입력을 받는 상태. 끄면 클릭이 아래 앱으로 통과 |
| 오버레이 | 모니터마다 뜨는 투명 판서 창 |
| 팔레트 | 도구·색·굵기를 고르는 떠 있는 UI(원형 기본, 가로형 선택) |
| 보드 | 화이트·블랙보드 전체 화면 판서 면(여러 페이지) |
| 라이브 줌 / 정지 줌 | 마우스를 따라 확대 / 현재 화면을 멈추고 확대 |
| 통과 모드 | 판서를 유지한 채 `U`를 누르는 동안만 아래 앱으로 입력을 전달 |
| 화면 구성 프리셋 | 주·보조 모니터 배치(3×3 격자)를 저장해 한 번에 적용하는 설정 |
| `.pansetting` | 설정 내보내기·가져오기 JSON 파일(macOS·Windows 공용) |
| WGC / ScreenCaptureKit | Windows / macOS의 화면 캡처 API(줌·내보내기에 사용) |

## 2. 사업 목표
### 2.1 해결하려는 문제
1. 수업 중 앱 전환 없이 어떤 화면 위에도 판서하기
2. 작은 글자·코드를 학생이 볼 수 있게 확대하기(판서 포함)
3. 수업·쉬는 시간을 시계 기준으로 정확히 관리하고 쉬는 시간에 음악 재생하기
4. 멀티 모니터·프로젝터·펜 태블릿 환경에서 판서를 잃지 않기
5. macOS와 Windows 강사가 같은 설정·단축키로 쓰기

### 2.2 기대 효과
- 판서·줌·타이머를 한 앱으로 통합해 수업 흐름 끊김을 줄인다.
- `.pansetting`으로 기관 표준 설정을 배포하고 새 PC로 이전한다.
- 외부 의존성·서버·계정 없이 로컬에서만 동작해 도입·보안 부담이 작다.

### 2.3 성공 지표
| 지표 | 목표 | 측정 방법 | 현재 |
|---|---|---|---|
| 줌 프레임률 | ≥ 50 fps | WGC 종료 로그의 프레임 수 / 시간 | 52 fps (Windows VM). macOS [확인 필요] |
| 유휴 CPU | ≤ 1 % | 작업 관리자·활동 모니터 | 0.00 % (Windows VM) |
| 상주 메모리 | ≤ 150 MB [가정] | 작업 관리자 | 89 MB, 판서 후 96 MB (Windows VM) |
| 판서 입력 비용 | ≤ 1 ms/점(CPU) | 합성 입력 스크립트 | 0.3~0.7 ms (Windows VM) |
| 내보내기 중 UI 점유 | ≤ 150 ms | `ui_blocked` 로그 | 120 ms (Windows VM) |
| 파일럿 사용 | 강사 5명 · 2주 · 치명 결함 0건 [가정] | 사용 기록·이슈 | 미실시 [확인 필요] |

## 3. 도메인 정의
### 3.1 비즈니스 도메인 범위
교육 현장의 **대면·화상 강의 보조 도구**(화면 오버레이). 학습 관리·출결·콘텐츠 배포는 범위 밖이다.

### 3.2 주요 이해관계자
| 이해관계자 | 역할 | 관심사 |
|---|---|---|
| 강사 | 주 사용자 | 빠른 판서, 줌, 타이머, 펜 입력, 화면 공유 시 노출 제어 |
| 학생 | 시청자 | 판서·타이머 가독성 |
| 기관 IT 담당 [확인 필요] | 배포·표준 설정 | 설치 형식, 서명, 설정 배포, 보안 |
| 개발·운영(이경환) | 기획·승인·실기 확인 | 일정, 품질, 릴리스 |
| 구현 보조(Claude·Codex) | 분석·검수 / 구현 | 작업 지시서 단위 협업 |

### 3.3 현행 업무 프로세스 (As-Is)
| 단계 | 현행 방식 [가정] |
|---|---|
| 1 판서 | 슬라이드 도구의 펜 기능 또는 별도 판서 앱 사용(앱마다 다름) |
| 2 확대 | OS 확대 기능 또는 별도 도구, 판서와 분리 |
| 3 타이머 | 휴대폰·별도 타이머 앱, 쉬는 시간 문구·음악은 수동 |
| 4 설정 이전 | 도구별로 재설정 |

### 3.4 목표 업무 프로세스 (To-Be)
| 단계 | EduTools |
|---|---|
| 1 판서 | `⌃⌥P`/`Ctrl+Alt+P`로 어느 앱 위에서나 판서, 모드를 끄면 즉시 통과 |
| 2 확대 | `⌃⌥Z`로 라이브 줌, `P`로 정지 줌에서 바로 판서 |
| 3 타이머 | 수업 배지 + 쉬는 시간 전체 화면(종료 시각 기준), 음악 자동 재생·페이드·정지 |
| 4 설정 이전 | `.pansetting` 한 파일로 내보내기·가져오기(OS 간 호환) |
