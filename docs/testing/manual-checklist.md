# EduTools 수동·하드웨어 체크리스트

## 사용법

1. `./build.sh`로 빌드하고 `dist/EduTools.app`을 실행한다.
2. 아래 장비 매트릭스에 실제 장비와 OS를 기록하고, 각 결과 칸에 `YYYY-MM-DD · 앱 버전/커밋 · 통과|실패 · 메모` 형식으로 적는다.
3. 실패하면 재현 장비, 화면 구성, 입력 장치, 실제 결과를 함께 기록한다. 한 장비에서 확인하지 않은 항목은 통과로 표시하지 않는다.

> **안전 안내:** 화면 구성 적용 항목은 실제 디스플레이의 미러링·배치를 바꾼다. 중요한 작업을 저장하고 단순한 단일/확장 프리셋부터 확인한 뒤 미러링·복잡한 배치를 시험한다.
