# EduTools E2E 스모크

T4는 Swift 모듈 안의 객체가 아니라 실제 `EduTools.app` 번들을 새 프로세스로 실행한다. OS 수준 키보드·마우스 입력, AX 메뉴·창, 화면 캡처 픽셀을 함께 확인하므로 로그인된 사용자 세션에서만 실행한다.

## 실행 전 권한과 위험

E2E를 실행하는 터미널 앱에 아래 권한을 먼저 부여한다.

| 요구 환경 | 시스템 설정 위치 | 필요한 이유 |
| --- | --- | --- |
| WindowServer | 로그인된 macOS 그래픽 세션 | 실제 창과 화면 좌표 사용 |
| 손쉬운 사용 | 개인정보 보호 및 보안 → 손쉬운 사용 | `CGEvent` 입력 주입과 AX 메뉴·창 탐색 |
| 화면 및 시스템 오디오 녹음 | 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음 | 스크린샷 픽셀과 줌 캡처 |

시험은 실제 마우스와 키보드를 장악한다. 사전 점검을 통과하면 `이 시험은 마우스·키보드를 제어합니다. 10초 안에 Ctrl-C 로 취소`를 출력하고 대기한다. 반복 개발에서만 `EDUTOOLS_E2E_NO_COUNTDOWN=1`로 이 대기를 생략할 수 있다. 사용자의 EduTools가 이미 실행 중이면 설정·핫키 충돌을 피하려고 시작하지 않는다.

## 실행과 격리

먼저 앱 번들을 만들고 E2E만 따로 실행한다. `all`과 `./build.sh test`에는 E2E가 포함되지 않는다.

```bash
./build.sh
scripts/test.sh e2e
scripts/test.sh e2e --app /path/to/EduTools.app
EDUTOOLS_E2E_APP=/path/to/EduTools.app scripts/test.sh e2e
```

대상 앱 우선순위는 `--app`, `EDUTOOLS_E2E_APP`, `dist/EduTools.app` 순이다. 각 시나리오는 새 앱 프로세스와 새 `UserDefaults` suite를 사용한다. 하니스가 만든 임시 디렉터리를 `EDUTOOLS_DATA_DIR`로, 고유 suite 이름을 `EDUTOOLS_DEFAULTS_SUITE`로 전달하므로 사용자의 설정·보관 파일을 읽거나 쓰지 않는다. 종료 시 정상 종료를 먼저 요청하고, 남은 프로세스만 강제 종료한 뒤 suite와 임시 디렉터리를 정리한다.

## 시나리오와 위험 근거

| # | 시나리오 | 목적 | 빨갛게 만들어야 하는 제품 회귀 |
| --- | --- | --- | --- |
| 1 | 실행·정상 종료·신규 크래시 리포트 0 | 번들 생명주기 스모크 | 시작 크래시, 종료 교착, 비정상 종료 |
| 2 | 기본 핫키 → 판서 오버레이 | Carbon 핫키와 창 경로 연결 | 기본 바인딩·등록·오버레이 활성화 단절 |
| 3 | 획 픽셀 → Undo로 복원 | 실제 입력부터 명령 스택·렌더까지 연결 | 드래그 입력, 렌더, Undo 중 하나의 회귀 |
| 4 | 우클릭 드래그로 지우기 | 보조 버튼 임시 지우개 경로 | 우클릭 소유권 또는 지우개 적용 회귀 |
| 5 | `M` 팔레트 도구 선택·즐겨찾기 저장 | 팔레트 키 탐색과 설정 영속 연결 | 팔레트 포커스, 명령 실행, 즐겨찾기 저장 회귀 |
| 6 | 단축키 변경 저장·재실행·실제 핫키 | override 영속과 재등록 연결 | 설정 저장, 카탈로그 해석, Carbon 재등록 회귀 |
| 7 | 줌 시작·종료 | ScreenCaptureKit와 전역 핫키 연결 | 권한 처리, 캡처 창 생성·정리 회귀 |
| 8 | 메뉴바에서 설정 창 열기 | 상태 메뉴와 설정 컨트롤러 연결 | AX 메뉴 노출 또는 설정 창 생성 회귀 |
| 9 | 메뉴바 화면 구성 목록 펼치기 | 프리셋 목록의 안전한 조회 경로 | 하위 메뉴 구성·설정 진입점 회귀 |

## 실패와 UNRUNNABLE 해석

| 결과 | 의미와 조치 |
| --- | --- |
| 종료코드 1 | 컴파일 또는 시나리오 실패다. 첫 실패 메시지와 `Tests/E2ETests/__artifacts__/<시험>-<시각>.png`를 함께 확인한다. |
| 종료코드 3 + WindowServer | GUI 로그인 세션의 터미널에서 다시 실행한다. |
| 종료코드 3 + 손쉬운 사용 | 실행 터미널을 손쉬운 사용 목록에서 허용한 뒤 터미널을 다시 시작한다. |
| 종료코드 3 + 화면 기록 | 실행 터미널을 화면 기록 목록에서 허용한 뒤 터미널을 다시 시작한다. |
| 종료코드 3 + 실행 중 EduTools | 사용자 앱을 정상 종료한 뒤 다시 실행한다. |

화면 구성 메뉴 시험은 목록 표시까지만 확인하며 프리셋을 적용하지 않는다. 실제 디스플레이 재배치와 복구는 화면·수업 환경을 바꿀 수 있으므로 T6 [`manual-checklist.md`](manual-checklist.md)에서만 수행한다.
